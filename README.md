# Verilog Project

This repository contains Verilog source files, testbenches, simulation outputs, and waveform files.

## Structure

- `src/` - Verilog source modules
- `tb/` - Testbench files
- `build/` - Generated simulation files
- `waveforms/` - Waveform outputs (`.vcd` files)
- `logs/` - Simulation/log output files

## Notes

- Source files can be found in `src/`.
- Testbenches are in `tb/`.
- Generated files are kept in `build/` or `logs/`.
- Waveforms are stored in `waveforms/`.
